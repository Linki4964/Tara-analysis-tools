# 架构图（结构图）绘制模块 —— 矢量画板

## 概述

本模块是车联网（汽车）网络安全 TARA（Threat Analysis and Risk Assessment，参照 ISO/SAE 21434）第 0 步「结构图」的**矢量绘图画板**：用户从右侧工具栏选择图元，直接在画布上拖拽/点击绘制；图内**所有内容都是带真实坐标、可再次编辑的普通矢量对象**（可选中、拖动、改大小、改文字、删除），绘制结果可导出为 PNG / SVG / JSON。

画布是**无限画布（Infinite Canvas）**：没有固定纸张边界，可朝上/下/左/右任意方向无限平移，并可在视口内的任意空白位置绘图（图形坐标可为负）。左侧运行记录、右侧绘图工具栏、底部 AI 输入栏都作为**悬浮卡片**叠在画布上层，不会把画布区域挤压变小。

工具栏**不再是一个"结构化编辑器"**（不管理部件/服务/边界表格，也不保存语义模型坐标自动排版）。整张图就是一张白纸 + 一组矢量图元。底部 AI 栏仍可用来**快速打草稿**：AI 会按其语义理解生成一张四图元架构图，并落成普通可编辑矢量对象，之后完全由用户自由整理。

> **本文件是 AI 使用该模块的权威操作规范。AI 在辅助绘图（AI 生成 / 讲解用法 / 出图建议）前必须先完整阅读并遵循本文件。**

图元与含义（手工绘制、AI 生成均遵循）：

| 图元 | 视觉 | 建议语义 |
|------|------|----------|
| 矩形 | 实线圆角框 | 整车部件/组件（ECU、网关、域控制器、云端、APP…），是承载服务/接口的宿主 |
| 虚线矩形 | 灰色虚线圆角框 | 边界 / 安全域；整图最外圈虚线框即"相关项 Item"范围框 |
| 圆形 | 白底椭圆/圆 | 挂在部件上的 服务/接口（也可做数据流端点） |
| 单向 / 双向箭头 | 线段 + 端头 | 数据流方向（单向 → / 双向 ⇄），从发送端指向接收端 |
| 文字 | 纯文本 | 标注：连线标签、说明、角标等 |

## 二、手动绘制（主要用法）

**使用流程**：先在右侧竖向工具栏点选一个图元 → 回到画布操作 → 用「选择」做排版微调。所有绘制都会**实时自动保存**并记一步撤销历史。

### 各工具的操作

| 工具 | 操作 |
|------|------|
| 选择 / 移动 | 单击 = 选中（蓝色虚线框 + 8 个手柄）；按住拖动 = 移动；拖手柄 = 改大小；**空白处按住左键拖出选框 = 框选多个**（整组拖动 / 删除 / 复制 / 置顶置底）；`Ctrl/⌘+单击` 可加选 / 取消单个；**双击文字或组件名**可直接改字；`Delete` / `Backspace`（或工具栏垃圾桶）删除选中项 |
| 矩形 | 按住左键拖拽 = 画实线矩形；单击空白处 = 放一个 150×96 的默认矩形 |
| 虚线矩形 | 按住拖拽 = 画虚线矩形（边界/安全域/Item 外框）；单击放默认虚线矩形 |
| 圆形 | 按住拖拽 = 画圆/椭圆（服务、接口）；单击 = 放直径 90 的圆 |
| 单向箭头 | 见下方「智能连线」 |
| 双向箭头 | 见下方「智能连线」 |
| 文字 | **单击**画面任意位置即输入文字；`Enter` 确认，`Shift+Enter` 换行，`Esc` 取消 |

### 框选与批量（选择工具下）

- **在空白处按住左键拖出蓝色选框**，凡与选框相交或被其框住的图形都会选中，松开即组成一组；可向任意方向拖框。
- **拖动组中任意一个成员 = 整组一起移动**，成员相对位置不变；`Delete`/`Backspace` 或右键「剪切 / 复制 / 删除 / 置于顶层 / 置于底层」都作用于整组。
- **`Ctrl/⌘ + 单击`** 某个图形 = 把它加入 / 移出当前选区；**`Ctrl/⌘ + 拖选框`** = 把框住的图形追加进选区。
- 单击空白处清除选择；单击某个未选图形改为只选它并可单独拖动；右键点击已在组内的图形会保留整组再弹菜单。
- 框选主要用于批量移动、删除、复制与调图层；**改大小（8 手柄）与双击改字需先把它单独选中**。

### 智能连线（画数据流的推荐方式）

- 先选右侧**单向箭头或双向箭头**工具；
- **单击**某个矩形 / 圆 → 该图形四边浮现 4 个朝外的小箭头（连接点）；
- 从一个连接点**按住拖向**另一个矩形 / 圆 → 生成箭头线；松开时目标被绿色虚线框高亮即表示**已吸附连接**；
- 智能连接线的两端**绑定在图形上**：之后拖动或改大小图形，线会自动裁剪到图形边缘并跟随移动；
- 若只想随手画线段，也可在空白处直接拖拽得到自由线；
- 删除某条线：切回「选择」点线（两端出现小手柄），按 `Delete` 或右键删除。

### 右键菜单与图层

- 在图形上**右键**会选中该图形并弹出菜单：**剪切 / 复制 / 粘贴 / 删除 / 置于顶层 / 置于底层**；空白处右键只提供「粘贴」。
- 快捷键：`Ctrl/⌘+X` 剪切、`Ctrl/⌘+C` 复制、`Ctrl/⌘+V` 粘贴（对象级剪贴板）。
- 「置于顶层 / 置于底层」调整对象前后遮挡顺序（后画的在上）。

### 视图平移与缩放（无限画布）

- 画布没有大小限制：任何空白处都可绘图（坐标可为负），没有固定纸张边缘。
- **鼠标中键按住拖动**平移视角（直接移动画布，而不是移动滚动条），画布空白/图形上都可用。
- 顶部导航栏按钮：缩小 / 放大 / 100% / 适应视图；缩放以**视口中心**为锚点，画面内容保持在你注视的位置不变。
- 「适应视图」自动把当前所有图形居中并缩放到合适比例；新内容超出视野后可再次使用。

### 可编辑对象范围

- 所有对象都可：选中、拖动、改大小（框 8 手柄 / 箭头两端手柄）、删除、复制、置顶置底。
- **双击可改文字的对象**：自由文字标注，以及带标题带的矩形（矩形顶部色带内显示的名称）。
- 每次拖动/改字/增删/置顶置底都只记**一步**撤销历史，不会刷屏。

### 撤销 / 重做 / 快捷键

- 顶部导航按钮，或 `Ctrl+Z` / `Ctrl+Shift+Z`（`Ctrl+Y` 亦可）；最多回溯 50 步，覆盖手动绘制与 AI 生成的全部操作。

## 三、AI 辅助生成（可选草稿）

- 在底部输入栏用自然语言描述想画的系统，例如：
  > TBOX 主控通过整车 CAN 总线连接 VCU 与中央网关；手机 APP 经 TSP 云端远程下发控制指令；攻击者可能经蓝牙或 OBD 口进入；在车内划分安全域，网关处有防火墙。
- AI 按第四节语义生成一张架构图草稿，**落成普通可编辑矢量对象**（实线矩形/虚线矩形/圆/箭头/文字），并整体替换画布内容。
- AI 是"打草稿"工具而非结构约束：生成后对象坐标自由、可被任意移动/改大小/删改；若画布此前已有内容，旧内容会保留在**撤销历史**中（AI 生成后日志会提示"可一步恢复"）。
- AI 生成遵循第四节最佳实践组织画面；如用户在图面上已手工画好一部分，AI 出图前应向用户说明它将覆盖画布、旧内容可撤销。

## 四、图元语义与 TARA 绘图最佳实践

### 1. 矩形 —— 部件/组件
部件是图中的实体承载者。语义上可参考下述 `category` 分类习惯（AI 生成时用不同配色区分，手工绘制建议也用相同含义区分）：

| category | 视觉 | 典型内容 |
|----------|------|----------|
| hardware 硬件 | 蓝 | ECU、中央网关、传感器、执行器、控制器、OBD、HSM 等物理器件 |
| software 软件 | 紫 | 应用软件、固件、操作系统、中间件、云端后台逻辑 |
| network 网络/总线 | 青 | CAN/CAN FD、车载以太网、蓝牙、蜂窝等总线/协议通道（**用矩形表达总线，不另造图元**） |
| external 外部实体 | 绿 | 外部系统、手机/钥匙等用户设备、云端、第三方、攻击者（一律视作"外部"） |
| control 安全控件 | 玫红 | 防火墙、IDS/IPS、认证、访问控制、加密模块、安全存储等既有防护 |

### 2. 圆形 —— 服务/接口/敏感数据
圆形表示部件上承载的、有安全含义的接口或数据（远程控制、OTA、诊断口、日志、密钥/凭据等）。**圆应画在其宿主部件旁边/边上**，不要独立成图。双击其文字可改名。

### 3. 虚线矩形 —— 边界 / 安全域 / Item 外框
- 车内信任区域（如"车内安全域""隔离预留域"）用虚线矩形圈起来，虚线框包住其成员。
- 整图**最外圈的虚线矩形是"相关项 Item"的范围框**，其标题即相关项名称；外部实体应画在 Item 外框**之外**。
- 需要时可在框上加一行文字标题（用"文字"工具，或用带标题的标题带）。

### 4. 箭头 —— 数据流
- 单向 = 数据从 A 流向 B（发送方 → 接收方）；双向 = 双方互发（请求/响应、收发一体的链路），画**双向箭头**。
- 推荐用「箭头工具」**单击一个矩形/圆 → 图形四边出现 4 个朝外的连接点 → 从连接点按住拖向目标矩形/圆**：生成的箭头是**智能连接线**，两端绑定在图形上，之后图形被拖动/改大小时线会自动裁剪贴边跟随（连接细节见二、手动绘制「智能连线」）。
- 如需可脱离连接的线段，在空白处直接拖拽即可得到自由线；连线标签用「文字」工具就近放一个标注（如"下发指令""车云交互"）。

### 5. 手工绘制注意
- **先划边界再填内容**：先圈出 Item 与安全域，再往里放部件；外部实体（云端/APP/攻击者/诊断仪）画在 Item 框外。
- **总线用矩形表达**：整车 CAN 等画成一个 network 矩形，用两条箭头（TBOX→CAN、CAN→VCU）体现拓扑。
- **敏感资产显式标注**：密钥、个人数据、位置等作为服务圆挂到存放/流转的部件上，或作为箭头/文字标注写明。
- **外部实体必须画出**：一切与系统交互的外部对象都入图，便于后续威胁分析引用。
- **箭头方向真实**：按真实流向画（发送→接收），双向才用双向箭头；不臆造未提及的连接，确需合理推断应向用户说明。

## 五、数据管理与导出

- **自动保存**：绘制内容（`{ name, shapes }` 的矢量对象清单，含坐标）实时写入浏览器 localStorage，key 为 `tara-arch:<runId>`（无 run 时用 `tara-arch:pending`）；刷新自动恢复。
- **兼容旧格式**：若读到旧的语义格式（含 `components` / `schemaVersion` 的 JSON），会自动转换成可编辑矢量对象后再展示。
- **导出**（顶部导航/菜单）：
  - **PNG**：2x 高清位图；
  - **SVG**：矢量源文件（仅含图形内容，不携带选中框等界面元素），可继续编辑；
  - **JSON**：当前 `{ name, shapes }` 矢量对象快照，可备份与再次导入。
- **下一步**：点击右上角"下一步"进入后续 TARA 步骤；当画布上存在**至少一个非纯文字对象**时才允许进入。
